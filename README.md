# Beyond the Singularity

Android test build for **Beyond the Singularity**, an interactive science/civilization incremental game spanning Eras 13–19.

## Android test APK
A GitHub Actions workflow builds a debug APK automatically from the bundled Android project.

After a successful build:
1. Open **Actions** in this repository.
2. Open the latest **Build Android Test APK** run.
3. Download the artifact named **beyond-the-singularity-debug-apk**.
4. Unzip it and install `app-debug.apk` on an Android device.

The test build is landscape/fullscreen and bundles the game locally for offline play.
